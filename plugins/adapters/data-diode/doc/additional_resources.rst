********************
Additional Resources
********************

This section contains a list of additional resources for |DATADIODE_NAME|.
The following resources are not detailed in this documentation because
they contain their own README file.

Examples
^^^^^^^^

Examples are located under ``<RTI Connext Gateway main folder>/examples/data-diode``.

Tests
^^^^^

Tests are located under ``<RTI Connext Gateway main folder>/plugins/adapters/data-diode/test``
If you have provided CMake with an installation directory, they will be under
``<CMake Installation directory>/test/data-diode``.
