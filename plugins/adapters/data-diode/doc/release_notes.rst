Release Notes
=============

First release (June 2025)
--------------------------

#. First release of the |DATADIODE_NAME| plugin for |RTI_RS|.

Supported Platforms
-------------------

|DATADIODE_NAME| is expected to build and run on the platforms in
:numref:`TableSupportedPlatforms`.

.. list-table:: Supported Platforms
    :name: TableSupportedPlatforms
    :widths: 20 80
    :header-rows: 1

    * - Platform
      - Operating System

    * - Linux systems
      - All Linux platforms supported by |RTI_RS|.
    * - macOS systems
      - All macOS platforms supported by |RTI_RS|.
    * - Windows systems
      - All Windows platforms supported by |RTI_RS|.
